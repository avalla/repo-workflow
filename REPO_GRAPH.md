# Repository map

- `core/`: shared authority, evidence and workflow contracts.
- `schemas/`: configuration, profile, preset, lock and gate-evidence schemas.
- `profiles/`: representative composable modules; `presets/`: pinned selections.
- `skills/`: canonical bounded procedures, loaded individually.
- `adapters/`: discovery contracts for generic Markdown, Codex and Claude Code.
- `templates/`: initialize-once project memory templates.
- `docs/`: resolution, ownership, provenance, ADRs and current status.
- `tests/fixtures/`: example projects, invalid inputs and future behavioral scenarios.
- `tests/validate_contracts.py`: contract checks only; no production tooling.

No `cli/` exists until Milestone 2. ROADMAP.md owns milestone order.
