# Repository map

- `core/`: shared authority, evidence and workflows.
- `schemas/`: configuration, profile, preset, lock and evidence contracts.
- `profiles/`, `presets/`: representative modules and pinned selections.
- `skills/`: canonical bounded procedures, loaded individually.
- `adapters/`: generic, Codex, Claude Code and Antigravity discovery.
- `templates/`: initialize-once project memory.
- `repo_workflow/io.py`: strict JSON, paths, snapshots and atomic writes.
- `repo_workflow/compose.py`: scoped resolution, origins and monotonic gates.
- `repo_workflow/install.py`: rendering, reviewed initial plans, journals and apply.
- `repo_workflow/__main__.py`: inspect/plan/apply/doctor CLI.
- `docs/`: contracts, provenance, ADRs, reports and status.
- `tests/validate_contracts.py`: schema/catalogue checks.
- `tests/test_tool.py`: executable disposable-target acceptance checks.
- `tests/fixtures/`: project examples, invalid inputs and M2/M3 scenario inventory.

ROADMAP.md owns milestone order. Updates and recovery execution belong to M3.
